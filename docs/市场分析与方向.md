# 市场分析与方向

> 结论先行：**国内有市场，但不在"再做一套学习机"这条线上。真正的空位是「诊断可视化」——把"孩子卡在哪"从一句模糊的评语变成一张能看、能钻、能讲给家长听的 3D 地图。这条线和我们已有的 3D 课件能力正好接得上，而且不碰双减红线。**

---

## 一、市场规模（有出处，且标注可信度）

| 口径 | 数字 | 来源与可信度 |
|---|---|---|
| 全球 AI in Education | 2024 年 42.6 亿美元 → 2032 年 327.6 亿美元，CAGR 29% | SNS Insider（通稿级研报，方向可信、绝对值仅供参考） |
| 全球 AI in K-12 | 2024 年 3.7 亿 → 2032 年 52.4 亿美元，CAGR 39% | SNS Insider（同上） |
| 中国教育智能硬件 | 2023 年 807 亿元 → 2025 年破 1000 亿元，AI 学习机占比 >60% | 中研普华（国内行业咨询，口径偏乐观） |
| 中国智慧教育 | 2025 年约 2800 亿元 → 2026 年约 3500 亿元 | IIM 信息（**可信度低**，来源单一、数字过大，仅作量级参考） |
| 家长付费意愿 | 超六成家长愿为 AI 教育产品付费，高收入家庭超七成 | 中研普华调研 |
| 获客成本 | 2026 年行业平均获客成本较 2025 上升 22%，约 286 元/人 | IIM 信息（可信度低，但趋势与常识一致） |

**怎么读这张表**：绝对值各家打架（420 亿 vs 2800 亿，口径完全不同），别拿去写 BP 当论据。可信的是三件事——① 增速是真的（29%–39%）；② 家长愿意掏钱是真的；③ 获客越来越贵是真的。第三条对我们这种没有投放预算的个人项目最关键：**别做需要买流量的 C 端 App**。

## 二、竞争格局：头部已经把"题库+自适应"这条路堵死了

| 玩家 | 打法 | 我们的相对位置 |
|---|---|---|
| 学而思（九章大模型 MathGPT） | 500 万题库 + 10 亿学习行为数据 → 精准学 Pro，高端市场约 35% | **打不过**：数据量差 6 个数量级 |
| 作业帮 | AI 诊断 + 名师直播课，份额约 22%，复购 >50% | 打不过：渠道和内容都碾压 |
| 科大讯飞 | AI 口语评测、学习机硬件 | 打不过：硬件和政企渠道 |
| 字节"显眼包" | 多模态 + 情感陪伴 | 打不过：投放和 IP |
| Squirrel AI | 自适应学习系统（松鼠 AI） | 打不过：十年数据积累 |

**共同特征**：全都靠**海量题库 + 海量行为数据**做自适应。这是数据军备竞赛，个人/小团队进场必输。

**但它们有一个共同短板**：诊断结果呈现方式几乎全是**雷达图 + 薄弱知识点列表 + 推题**。家长看到的是"你函数不行、方程不行"，看不到**为什么不行、从哪儿补、补完能解锁什么**。学而思精准学的报告是给教研人员看的，不是给家长看的。

→ **这就是空位：诊断的"可解释性 + 可视化 + 叙事"。** Marble 这套带原因的前置链，天生就是干这个的。

## 三、AI 对这条赛道的影响（不是"加个 AI"，是三层重构）

### 1. 内容生产成本塌方 → 知识图谱的价值反而上升
以前做一套小学知识体系要几百个教研老师写两年。现在 LLM 能批量生成知识点、讲解、变式题。**结果：内容不值钱了，"结构"更值钱了。** 谁都知道让模型讲"分数加减法"，但没人保证讲的内容踩在正确的依赖顺序上。前置依赖图就是那个"顺序保证"——它是把 LLM 从"会聊天"约束成"会教学"的骨架。

**对我们的意义**：Marble 已经把欧美这套骨架免费给我们了。我们要做的不是重造骨架，是**造中国教材那一层映射**。

### 2. 对话式诊断替代选择题式测评
Marble 的 `assessmentPrompt` 字段设计得很聪明——它不是题目，是一句**给老师看的提问建议**（"如果孩子说'The dog'，他能不能告诉你这不是完整句子？"）。这在 2026 年的用法是：**直接喂给本地 LLM 当提问模板**，让模型用自然对话判断孩子会不会，而不是让孩子做 20 道选择题。

优势：孩子不累、家长看得懂、不需要题库。这恰好绕开了头部厂商的数据壁垒——**我们不需要 500 万题库也能做诊断**。

### 3. 本地推理让"隐私级"成为可能（这是爹的核心资产）
头部产品全在云端，儿童数据合规是它们最大的成本项（2024 年某品牌因未加密儿童语音数据被欧盟罚 2.3 亿元）。我们本来就做局域网/本地模型部署（医助通同一套架构），**"孩子数据不出这台机器"是可以写进合同的销售话术**，头部厂商做不到。

## 四、合规边界（决定能不能做，先划清楚）

双减管的是**学科类校外培训**，不是教育工具本身。边界这样划：

| 做法 | 判断 |
|---|---|
| 卖课、直播授课、超前教学、提分承诺 | ❌ 红线 |
| 题库刷题、应试排名 | ⚠️ 敏感 |
| **学情诊断 / 能力测评 / 学习路径可视化** | ✅ 属于工具与评价，非学科培训 |
| **家长端报告 + 家庭亲子学习活动建议** | ✅ 政策鼓励方向（家庭教育促进法） |
| 卖给学校/教育局（精准教学、备课辅助） | ✅ 政策明确支持（教育新基建） |
| 科学 / 计算机 / 学会学习 / 生活技能 等非学科科目 | ✅ 双减基本不覆盖 |

**定位必须写成**："学习诊断与可视化工具"，不是"AI 家教"、不是"提分"。措辞决定生死。

另外两条硬约束：
- 未成年人数据：本地化存储 + 不上传，是我们天然优势，但要写清隐私政策。
- 上游课标文本：NGSS/IB 全文不能直接用（要授权）。**只用 topics + 前置图 + Marble 原创描述**，这部分干净。

## 五、和 3D 课件（brother-3d-course）的关系：不是相似，是互补的两半

爹说"和我们的 3D 课件有相似"——准确说是**同一条链路的上下游**：

```
诊断（找卡点）              教学（补卡点）
─────────────              ─────────────
知识图谱 + 前置回溯   →→→   3D 课件
Learning Map                brother-3d-course
"你卡在 Counting in 2s"     "来，把这个点钻开看懂"
```

我们已经有后半截（3D 课件引擎、DECK3D 模板、语音播报、启动器、按教材单元批量产册的流水线）。缺的是前半截——**课件现在是我们挑主题做，不知道家长真正需要哪个主题**。

接上之后变成：

1. 诊断出卡点 → 2. 卡点自动映射到已有课件（或标记"这个卡点还没有课件"）→ 3. 课件选题不再靠猜 → 4. 课件从"内容产品"升级成"诊断闭环里的处方"。

**这才是 3D 课件真正的商业化路径**：单卖课件，家长不觉得值；卖"我知道你孩子卡在哪 + 我有一张针对这个卡点的 3D 讲解"，家长觉得值。

而且技术栈完全复用：都是单文件 HTML + three.js + 本地化 vendor + 零构建 + 局域网可跑。DECK3D 引擎的 `flyTo` 视角接口和这里的 `__VIZ.select()` 一接，就能做"从图谱里点一个卡点 → 镜头飞入 → 课件在 3D 场景里展开"。

## 六、我们的切入点（按投入产出排序）

### 方向 A：诊断可视化 SaaS（最推荐，先做这个）
- 产品：家长上传孩子错题/作业照片 → 本地多模态模型判错 → 图谱回溯 → 出一张**3D 卡点地图 + 一页人话报告**（"卡在 2 岁半该会的地基，不是三年级的问题"）
- 卖法：**按次/按报告卖，不做 App 不做投放**。渠道复用医助通已定案的诊所模式（诊所自建服务器 ¥5000 包干 + APK 隧道接入）——同一批客户、同一套部署、同一份合同框架
- 为什么能赢：头部做不了本地化，做不了带原因的链，做不了给家长看的叙事

### 方向 B：非学科 3D 课件 + 图谱联动（第二优先）
- 用图谱里 **Science 547 / Computing 21 / Learning to Learn 18 / Life Skills 37** 这些非学科科目做 3D 课件选题池——双减基本不覆盖，且 Marble 的 evidence 字段直接给出"讲完孩子应该能做到什么"，等于免费的教学目标
- 柴予淳 7 岁正好在 5–12 覆盖区间，自家就是测试床

### 方向 C：B 端 / G 端工具（长线，别现在投）
- 精准教学、备课辅助、区域学情看板。政策明确支持，但销售周期长、要资质、要关系。个人阶段不碰。

### 方向 D：数据集本身的中国化（护城河，慢慢做）
- 把 1,590 点映射到人教版/统编版，加中文知识点和中文前置链。**这份衍生库按 ODbL 必须开源**——但开源它不亏：它是我们诊断引擎的地基，开源它反而形成标准卡位，别人用我们的映射就得回馈我们。真正的商业价值在引擎和服务，不在数据。

## 七、直白风险

1. **上游是营销产物**：Marble 是 3 人美国初创，v1 发布后 3 个月零更新。数据不会有人维护 → 我们必须自己校验、自己扩，不能指望上游。
2. **粒度仍偏粗**：数学只有 503 个点，做中国小学数学诊断不够细（人教版小学数学知识点量级在 1,500–3,000）。要自己扩。
3. **英文数据不能直接给中国家长看**：全量中文化是必须的重活，不是翻译一遍就行——中国教材的知识点切分和欧美不一样（比如"完整句子"在中国语文体系里对应的是另外的切法）。
4. **诊断准确率是命门**：判错一道题容易，判准"卡在哪一层前置"很难。一旦家长发现诊断不靠谱，这个产品就死了。必须先在自己孩子身上跑通、跑准，再谈卖。
5. **别做 C 端 App**：获客成本 286 元/人还在涨，我们没有投放预算。走已有渠道（诊所/私域/学校）比做 App 靠谱得多。

4. 之后再谈产品化和定价。
